# Review an ordered product

Open [your orders](/en/docs/account/orders), choose an order, and open its review page when the option is offered. The page lists order items, existing review status, and whether each item can be reviewed. Select **Write Review** for an eligible item, or **Edit Review** where an existing review can still be changed.

The review period is tied to delivery. The page reports the days remaining or says when the period has expired. Existing reviews can appear as pending, approved, or rejected. A disabled review button means that the item or order is not currently eligible.
