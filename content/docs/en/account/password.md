# Reset your password

1. On the login page, select **Forgot password**.
2. Enter the email address used by your account and submit the form.
3. Open the reset link sent to that address. The reset page requires the token in the link.
4. Enter and confirm a new password, then submit it.
5. Return to **Log in** and use the new password.

If the link is missing, expired, or invalid, use **Request new reset** and try the latest link. Keep reset links private.
