# المساعدة والإرجاع والسياسات

قد توفر مساحة عملك الصفحات العامة التالية:

| الصفحة | استخدامها |
| --- | --- |
| **مركز المساعدة** | معلومات الدعم والإجابات التي توفرها مساحة العمل. |
| **الإرجاع والاسترداد** | معلومات الإرجاع المعروضة قبل طلب المساعدة بشأن طلب. |
| **سياسة الخصوصية** | وصف مساحة العمل لكيفية التعامل مع المعلومات الشخصية. |
| **الشروط والأحكام** | الشروط المعروضة لهذه المساحة. |
| **مشتريات الشركات بالجملة** | معلومات المشتريات الكبيرة للأعمال عند توفرها. |

قد تختلف شروط هذه الصفحات بين مساحات العمل. اقرأ الصفحة المباشرة للمتجر الذي أنشأت فيه الطلب. احتفظ برقم الطلب عند طلب المساعدة.

لخطوات مفصلة، راجع [التواصل مع الدعم](/ar/docs/support/contact) أو [الإرجاع والاسترداد](/ar/docs/support/returns) أو [طلب شراء بالجملة](/ar/docs/support/bulk-purchases).
