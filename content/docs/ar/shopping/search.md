# البحث عن المنتجات وتصفيتها

افتح البحث عن المنتجات من واجهة المتجر أو من صفحة فئة. قد تعرض صفحة البحث تصفية حسب الفئة والسعر، وقائمة ترتيب، وأدوات عرض الشبكة أو القائمة.

1. أدخل كلمة بحث أو افتح بحث المنتجات لفئة معينة.
2. طبّق عوامل التصفية المناسبة.
3. غيّر الترتيب إذا لم تناسبك النتائج الأولى.
4. اختر بطاقة منتج لمراجعة السعر والتوفر والتفاصيل.

إذا لم تظهر منتجات، أزل بعض عوامل التصفية وحاول مرة أخرى. تابع إلى [اختيار منتج](/ar/docs/shopping/product).
