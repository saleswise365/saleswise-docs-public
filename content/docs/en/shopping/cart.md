# Review your cart

The cart page requires a signed-in customer account. It groups items by shop and shows each shop's subtotal.

1. Open **Cart** and review each item, price, and quantity.
2. Use the plus or minus controls to change a quantity. Use the remove control to take an item out of the cart.
3. Add an **Order note** if you need to provide instructions.
4. Check the subtotal. Delivery charges are shown at checkout.
5. Select **Checkout** to continue, or **Continue shopping** to add more items.

If the cart is empty, the page offers a **Continue shopping** action. Continue with [checkout](/en/docs/shopping/checkout).
