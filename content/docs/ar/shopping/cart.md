# مراجعة السلة

تتطلب صفحة السلة تسجيل الدخول بحساب عميل. تُجمّع المنتجات حسب المتجر وتعرض المجموع الفرعي لكل متجر.

1. افتح **السلة** وراجع كل منتج وسعره وكميته.
2. استخدم زري الزيادة والنقصان لتغيير الكمية، أو زر الحذف لإزالة المنتج.
3. أضف **ملاحظة للطلب** إذا احتجت إلى تقديم تعليمات.
4. راجع المجموع الفرعي. تظهر رسوم التوصيل عند إتمام الطلب.
5. اختر **إتمام الطلب** للمتابعة، أو **متابعة التسوق** لإضافة منتجات أخرى.

إذا كانت السلة فارغة، تعرض الصفحة خيار **متابعة التسوق**. تابع إلى [إتمام الطلب](/ar/docs/shopping/checkout).
