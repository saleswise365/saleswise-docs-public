# معلومات الإرجاع والاسترداد

افتح **الإرجاع والاسترداد** في واجهة متجر المستأجر لقراءة المعلومات المنشورة. قد تختلف التفاصيل حسب مساحة العمل والمنتج والطلب؛ اعتمد على الصفحة المباشرة للشروط الحالية.

لطلب معين، سجّل الدخول وافتح [تفاصيل الطلب](/ar/docs/account/order-details). احتفظ برقم الطلب ومعلومات المنتج عند التواصل مع الدعم. لا ترسل بيانات الدفع أو كلمات المرور في طلب دعم.
