# Find a client

Sign in to Saleswise Admin and open **Clients**.

1. Enter a name or other search term in the search field.
2. If needed, filter the list by status or plan.
3. Select the client to open its details.

The list and client details depend on the access granted to your Admin account. Return to [Saleswise Admin guides](/en/docs/platform).
