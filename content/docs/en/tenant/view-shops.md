# View shops

In a marketplace workspace, sign in to the tenant application and open **Administration → Shops**. This page lists the shops available to your account.

1. Use the search field or status filter to narrow the list.
2. Switch between table and card views if one is easier to scan.
3. Select **Refresh** to reload the current results.

The actions for adding, editing, or deleting shops appear only when your account can manage shops. A single-store workspace may not show this page. If you expected to see it, ask your workspace administrator about its configuration and your access.

Return to [store administration](/en/docs/tenant).
