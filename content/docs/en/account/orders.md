# Find and review orders

Sign in and open **My orders** from your account. Select **Order details** on an order to see its items and status. The order confirmation page also links directly to the new order after checkout.

An order may contain items from more than one shop; the confirmation page groups those items by shop. Keep the displayed order number for support requests.

A pending order can show a **Delete order** action. Use it only if you intend to remove that pending order. Review and rating options, when available, are tied to an existing order and product.

For problems with an order, see [help and returns](/en/docs/support/help).
