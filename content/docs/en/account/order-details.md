# Review an order

After checkout, select **View order details** on the confirmation page. You can also sign in, open **My orders**, and select **Order details** for an existing order.

Review the order number, status, products, quantities, and total. An order with products from multiple shops may show a separate shop breakdown. The confirmation page also displays the delivery address when the order has one.

If a review action appears for an eligible item, open it from the order detail page. For an order problem, use the workspace [help and returns pages](/en/docs/support/help).
