# Manage delivery addresses

Sign in and open **My addresses** in your account. Saved addresses appear as cards with the location, recipient, street, and phone number.

- Select **Add new address** to save another delivery destination.
- Use the edit control on a card to update that address.
- Use the delete control to remove an address you no longer need.

At checkout, choose the address for the current order. You need at least one address before confirming an order. Check the recipient and phone number before placing it.
